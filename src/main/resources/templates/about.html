Об программе Milkromug

Преамбула

Печать чатов средствами браузера («Сохранить как PDF») безжалостно режет сообщения: длинные ответы обрываются на середине страницы, блоки кода теряются, а в документ попадают сайдбары, кнопки и прочие элементы интерфейса. Бесплатных офлайн-инструментов такого класса не существовало — поэтому был создан Milkromug: локальная программа, которая собирает полный чат с ИИ и превращает его в чистый, правильно разбитый по страницам PDF.

Функционал

  • Захват переписки из любого веб-чата с ИИ одним кликом по закладке (букмарклет Milkromug Capture).
  • Локальный сервер на http://localhost:8080: приём чата, санитизация HTML, хранение последних 20 захватов в памяти.
  • Печатный предпросмотр с настройкой размера шрифта (чат 8–24 pt, интерфейс 10–22 px) и сохранением в PDF через диалог печати браузера.
  • Демо-чат на главной странице — можно посмотреть результат без curl.

Преимущества

  • Бесплатно — никаких подписок и лимитов.
  • Полностью офлайн — все данные остаются на вашем компьютере.
  • Открытый код — лицензия The Unlicense, делайте с кодом что хотите.
  • Java не нужна — JRE 21 уже встроена в портативный пакет.
  • Захват одним кликом — установили закладку один раз и пользуетесь.

Как скачать и запустить

  1. Скачайте Milkromug-portable-win64.zip со страницы Releases.
  2. Распакуйте в любую папку и запустите Milkromug\Milkromug.exe — откроется консольное окно с логами, держите его открытым.
  3. Откройте http://localhost:8080 в браузере.
  4. Чтобы остановить программу, закройте консольное окно или выполните памятку: taskkill /IM Milkromug.exe /F. Повторный запуск безопасен: второй экземпляр увидит занятый порт 8080 и корректно завершится.

About Milkromug

Preamble

The browser's built-in "Print to PDF" ruthlessly cuts chat transcripts: long answers break in the middle of a page, code blocks get lost, and sidebars, buttons and other UI clutter end up in the document. There were no free offline tools of this class — that is why Milkromug was created: a local program that captures the full AI chat and turns it into a clean, properly paginated PDF.

Features

  • Capture a conversation from any web AI chat with a single bookmarklet click (Milkromug Capture).
  • Local server at http://localhost:8080: receives the chat, sanitizes HTML, keeps the last 20 captures in memory.
  • Print preview with adjustable fonts (chat 8–24 pt, UI 10–22 px) and Save-as-PDF via the browser print dialog.
  • Demo chat on the home page — see the result without curl.

Advantages

  • Free — no subscriptions, no limits.
  • Fully offline — all data stays on your computer.
  • Open source — The Unlicense, do whatever you want with the code.
  • No Java required — JRE 21 is bundled in the portable package.
  • One-click capture — install the bookmark once, use it forever.

How to download and run

  1. Download Milkromug-portable-win64.zip from the Releases page.
  2. Unpack anywhere and run Milkromug\Milkromug.exe — a console window with logs opens; keep it open while the program runs.
  3. Open http://localhost:8080 in your browser.
  4. To stop the program, close the console window or run the cheat sheet: taskkill /IM Milkromug.exe /F. Relaunching is safe: the second instance detects busy port 8080 and exits gracefully.
