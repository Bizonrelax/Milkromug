☕ Как пользоваться

🔖 Настроить захват ℹ️ О программе
↖ Перетащи кнопку «Milkromug Capture» на панель закладок браузера — это нужно сделать только один раз.
Браузеры запрещают программам создавать закладки — это требование безопасности, поэтому автоустановка невозможна и подсказка обязательна. После перетаскивания просто кликай по закладке в любом чате с ИИ.

🔖 Страница букмарклета: /bookmarklet  ·  Об программе / About

  1. Нажми «Поднять» — откроется страница Milkromug Capture, и перетащи кнопку «Milkromug Capture» на панель закладок браузера.
  2. Открой чат с ИИ (chat.qwen.ai, chatgpt.com, gemini.google.com…) и кликни по закладке — чат будет отправлен в Milkromug.
  3. В новой вкладке настрой размер шрифта спиннерами и нажми «Сохранить в PDF» (печать → сохранить как PDF).

Захваченные букмарклетом чаты сохраняются в памяти (до 20) и открываются по ссылке /preview/{id}. Хотите посмотреть результат прямо сейчас — нажмите «Демо-чат без curl».

Для тех, кто предпочитает curl (технические примеры)

Windows cmd (одна строка, двойные кавычки, внутренние экранированы):

curl -X POST http://localhost:8080/chat -H "Content-Type: application/json" -d "{\"title\":\"Демо\",\"messages\":[{\"author\":\"user\",\"text\":\"Привет!\"}]}"

PowerShell:

Invoke-RestMethod -Uri http://localhost:8080/chat -Method Post -ContentType "application/json" -Body '{"title":"Демо","messages":[{"author":"user","text":"Привет!"}]}'
