Глоссарий (термины и этимологии)

Букмарклет (bookmarklet)
Слияние английских слов bookmark («закладка») и applet («апплет», маленькая программа). Это закладка браузера, в адрес которой вместо сайта записана небольшая JavaScript-программа: клик по такой закладке запускает код прямо на открытой странице. Букмарклет Milkromug захватывает переписку с ИИ и отправляет её на локальный сервер.
Лоадер (loader, «загрузчик»)
Особый букмарклет-«закладка-загрузчик»: в самой закладке лежит крошечная строка, которая при клике скачивает свежий код захвата с адреса http://localhost:8080/bookmarklet.js и выполняет его. Благодаря лоадеру букмарклет переустанавливать не нужно — обновляется код на сервере, а закладка остаётся.
Санитизация (sanitization)
От англ. sanitize — «очищать, делать безопасным». Это вырезание из HTML чужих тегов, стилей, скриптов и прочего мусора, который страницы чатов тащат вместе с сообщениями. Milkromug выполняет санитизацию на сервере библиотекой jsoup: в предпросмотр и PDF попадают только читаемые реплики, без CSS-правил вида .fd1gae{...} и служебного JS.
Репозиторий (repository)
От лат. repositorium — «хранилище». В разработке это хранилище исходного кода проекта с историей изменений (обычно на GitHub/GitLab). Репозиторий Milkromug доступен публично; ссылка — на странице «Об программе».
JSON
JavaScript Object Notation — текстовый формат обмена данными: {"author":"user","text":"Привет"}. Им букмарклет передаёт захваченный чат серверу, им же сохранённые чаты отдаются как экспорт.
curl
Утилита командной строки для запросов к HTTP-серверам (имя от Client URL). Пример проверки, что Milkromug жив: curl http://localhost:8080/.
localhost
Зарезервированное доменное имя «этот компьютер» (IP 127.0.0.1). Сервер Milkromug слушает http://localhost:8080 и доступен только с вашей машины — данные никуда не уходят.
Headless («без головы»)
Режим запуска без графического интерфейса и консоли (например, автоматизация в CI). В headless-режиме Milkromug не ждёт нажатия Enter при занятом порту и завершается сразу с кодом 0.
Markdown
Лёгкий текст с разметкой: **жирный**, # заголовок. Milkromug умеет экспортировать чаты в markdown (/preview/{id}?format=md).
DOM (Document Object Model)
«Дерево» открытой веб-страницы, которое видит JavaScript: каждый тег — узел дерева. Букмарклет читает реплики чата именно из DOM вкладки.
Селектор (selector)
Короткая запись-адрес узлов DOM, например section.message > div.content — «div.content внутри section.message». Для каждого сайта захвата (chat.qwen.ai, gemini, share.google/aimode…) подобраны свои точные селекторы сообщений.
Ярлык (shortcut)
В Windows — файл-ссылка (.lnk) на программу или страницу с собственной горячей клавишей. Milkromug создаёт ярлык «Milkromug Capture.lnk» на рабочем столе.
Горячая клавиша (hotkey)
Комбинация клавиш для быстрой команды. У захвата Milkromug это CTRL+SHIFT+G: откройте чат и нажмите — чат улетит в программу.

FAQ — частые вопросы

Зачем нужен букмарклет и почему нельзя читать чужие вкладки без него?
Браузер из соображений безопасности запрещает одной странице читать содержимое вкладок с другим сайтом (политика same-origin). Единственный способ «протянуть руку» внутрь вкладки с чатом — выполнить код в контексте самой этой вкладки, чем и является клик по букмарклету. Поэтому расширение или отдельная кнопка браузера здесь не нужны — достаточно закладки.
Надо ли переустанавливать закладку после обновления программы?
Нет. Перетащите один раз лоадер-кнопку со страницы /bookmarklet: она при каждом клике скачивает актуальный код захвата с локального сервера. Полный однострочник оставлен лишь как аварийный вариант (в блоке «Аварийный вариант» на странице /bookmarklet).
Чем кнопка «Поднять» отличается от «Настроить захват»?
По фактическому текущему коду главной страницы: «Настроить захват» — это обычная ссылка, которая открывает страницу /bookmarklet в той же вкладке. «Поднять» — кнопка-дубль: она открывает ту же страницу /bookmarklet в новой вкладке И дополнительно показывает плавающую подсказку «перетащи кнопку на панель закладок» (её можно закрыть крестиком и запомнить выбор чекбоксом «больше не показывать»). Обе кнопки ведут на установку букмарклета; разница — в новой вкладке и подсказке.
Куда вставлять однострочник вручную? (по браузерам)

Chrome (и Edge на Chromium):

  1. Показать панель закладок: Ctrl+Shift+B.
  2. Правый клик по панели → «Добавить страницу…» (Edge: «Добавить закладку…»).
  3. Имя: «Milkromug Capture»; в поле URL/Адрес вставить javascript:-строку.
  4. Сохранить — закладка появится на панели.

Firefox:

  1. Показать панель закладок: Ctrl+Shift+B («Вид → Панели → Панель закладок»).
  2. Ctrl+D (Добавить закладку) → в поле «Адрес» вставить javascript:-строку.
  3. Имя «Milkromug Capture» → «Готово».

Opera:

  1. Показать панель: Ctrl+Shift+B (Меню → Закладки).
  2. Меню → Закладки → «Добавить закладку…».
  3. В поле «URL» вставить javascript:-строку, сохранить.

Safari:

  1. Настройки → «Дополнения»: включить «Показывать меню „Разработка“».
  2. Меню «Разработка» → «Показать страницу закладок» (или Cmd+Shift+2).
  3. Снизу «+» → двойной клик по новой закладке → вставить javascript:-строку в URL.
  4. Перетащить закладку на панель закладок.

Яндекс.Браузер:

  1. Показать панель закладок: Ctrl+Shift+B.
  2. Правый клик по панели → «Добавить закладку…».
  3. В поле «Адрес» вставить javascript:-строку → «Готово».
Что такое санитизация и зачем она при захвате?
Страницы чатов отдают сообщения вместе с кучей служебного HTML (стили, скрипты). Санитизация отсекает этот мусор на сервере, иначе предпросмотр и PDF забиваются CSS-правилами вместо текста разговора.

📖 Glossary & FAQ for beginners

Glossary (terms and etymology)

Bookmarklet
A blend of bookmark + applet: a browser bookmark whose URL is a small JavaScript program. Clicking it runs the code inside the current page. The Milkromug bookmarklet captures your AI chat and posts it to the local server.
Loader
A tiny bookmarklet that fetches the fresh capture code from http://localhost:8080/bookmarklet.js on every click — so the bookmark survives app updates without reinstallation.
Sanitization
From Latin sanus, "to make clean": stripping foreign tags, styles and scripts out of captured HTML. Milkromug sanitizes with jsoup on the server, so previews and PDFs contain readable messages, not CSS junk.
Repository
From Latin repositorium, "storage place": the project's source-code store with full history (GitHub). The link is on the About page.
JSON
JavaScript Object Notation — a lightweight text data format used to transfer and export chats.
curl
A command-line HTTP client ("Client URL"). Check the server with curl http://localhost:8080/.
localhost
"This computer" (127.0.0.1). Milkromug listens on http://localhost:8080 only — your data never leaves your machine.
Headless
Running without GUI/console (CI). In headless mode Milkromug does not wait for Enter when the port is busy and exits with code 0.
Markdown
Lightweight text markup (**bold**, # heading); available via /preview/{id}?format=md.
DOM
Document Object Model — the tree of the open web page that JavaScript reads; the bookmarklet extracts chat messages from it.
Selector
A short address of DOM nodes, e.g. section.message > div.content. Each supported chat site has its own precise selectors.
Shortcut
In Windows, a .lnk file linking to a program/page with its own hotkey ("Milkromug Capture.lnk" on the desktop).
Hotkey
A keyboard combination for a quick command — Milkromug capture uses CTRL+SHIFT+G.

FAQ

Why a bookmarklet — can't the app read other tabs by itself?
No: the browser's same-origin policy forbids one page from reading a tab on another site. The only sanctioned way to run code inside the chat tab is a bookmarklet click. No extension needed.
Do I have to reinstall the bookmark after updating the app?
No — drag the loader button once; it downloads the current capture code from the local server on every click. The full legacy one-liner remains only as an emergency fallback inside "Аварийный вариант"/details on /bookmarklet.
What is the difference between "Raise" and "Configure capture"?
Per the actual current code of the main page: "Configure capture" (🔖 Настроить захват) is a plain link that opens /bookmarklet in the same tab; "Raise" (🚀 Поднять) is a duplicate button that opens the same /bookmarklet page in a NEW tab and additionally shows the floating drag-to-bookmarks-bar hint (dismissable via its close button and the "don't show again" checkbox stored in localStorage). Both lead to bookmarklet setup; the difference is the new tab plus the hint.
Where do I paste the one-liner manually?

Chrome: Ctrl+Shift+B to show the bookmarks bar → right-click the bar → "Add page…" → name "Milkromug Capture", paste the javascript: string into URL → Save.

Edge: Ctrl+Shift+B → right-click the bar → "Add bookmark…" → paste the javascript: string into the Address field → Save.

Firefox: Ctrl+Shift+B for the bookmarks toolbar → Ctrl+D → paste the javascript: string into the Address field → Done.

Opera: Ctrl+Shift+B → Menu → Bookmarks → "Add bookmark…" → paste into URL.

Safari: Settings → Advanced → show Develop menu → Develop → Show Bookmarks page → "+" → edit the new bookmark, paste the javascript: string into URL, drag to bar.

Yandex.Browser: Ctrl+Shift+B → right-click the bar → "Add bookmark…" → paste into the Address field → Done.

What is sanitization and why does capture need it?
Chat pages ship messages wrapped in service HTML (styles, scripts). Server-side sanitization strips that junk so previews and PDFs stay readable.
